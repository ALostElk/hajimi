一款基于东海帝王哈基米形象开发的趣味科学计算器，集成了强大的计算功能、可爱的角色表情、丰富的音效反馈和三大特色功能。

## ✨ 项目亮点

### 🎯 核心特色
- **🤖 AI智能评论**：基于通义千问的哈基米AI助手，提供个性化反馈
- **🎵 丰富音效系统**：24个精选曼波音效，数字按键音阶变化
- **😺 动态表情系统**：9种表情根据计算结果智能切换
- **🧮 强大计算能力**：基础运算、科学计算、健康计算全覆盖
- **🎉 三大新功能**：音效播放器、幸运数字生成器、计算历史记录

### 🎨 设计理念
将传统的科学计算器与趣味元素完美结合，通过可爱的角色表情、丰富的音效反馈和智能的AI评论，为用户提供独特的计算体验。

## 🚀 快速开始

### 系统要求
- **操作系统**：Windows / macOS / Linux
- **Python 版本**：3.7 或更高
- **依赖库**：
  - tkinter（Python 标准库）
  - pygame >= 2.1.0
  - Pillow >= 9.0.0
  - dashscope（可选，用于AI功能）

### 安装与运行

1. **克隆项目**
```bash
git clone https://github.com/your-username/hajimi.git
cd hajimi
```

2. **安装依赖**
```bash
pip install -r requirements.txt
```

3. **运行程序**
```bash
python python/main.py
```

**Windows用户**：可直接双击 `python/启动计算器.bat` 快速启动

### 常见问题解决

**tkinter 导入错误**：
- **Windows**：重新安装 Python 并勾选 "tcl/tk and IDLE" 选项
- **Ubuntu/Debian**：`sudo apt-get install python3-tk`
- **macOS**：`brew install python-tk`

## 🧮 功能详解

### 基础计算功能
- **四则运算**：加（+）、减（-）、乘（×）、除（÷）
- **括号支持**：支持多层嵌套括号计算
- **小数运算**：精确的浮点数计算
- **百分比**：支持百分号（%）运算

### 科学计算功能
- **三角函数**：sin、cos、tan（支持度数/弧度模式切换）
- **数学函数**：
  - `sqrt(x)` - 平方根
  - `ln(x)` - 自然对数
  - `lg(x)` - 常用对数（以10为底）
- **数学常量**：
  - `pi` - 圆周率 π (3.141592...)
  - `e` - 自然常数 e (2.718281...)

### 健康计算功能
- **BMR 计算器**：基础代谢率计算
  - 使用 Harris-Benedict 修正公式
  - 支持性别、年龄、身高、体重参数
  - 提供个性化健康建议和AI生成报告

### 交互体验
- **动态角色表情**：根据计算结果展示不同表情
  - 默认、开心、满意、惊讶、生气、暴怒、难过、困倦、无表情
- **音效反馈**：丰富的曼波音效库
  - 数字按键：低-中-高音阶变化（1-3低音、4-6中音、7-9高音）
  - 运算符：固定音效（+曼波、-干脆、×可爱、÷升调）
  - 功能键：随机音效增加趣味性
  - 成功/失败：专属反馈音效
  - 支持静音模式切换
- **美观界面**：现代化 UI 设计
  - 粉色主题配色
  - 按钮悬停和点击动画效果
  - 结果高亮显示

## 🎮 使用指南

### 基础操作
1. **数字输入**：点击数字按钮或使用键盘输入
2. **运算符**：点击 `+`、`-`、`×`、`÷` 按钮
3. **计算结果**：点击 `=` 按钮或按 `Enter` 键
4. **清空输入**：
   - `AC` 按钮：清空所有内容
   - `⌫` 按钮：删除最后一个字符（Backspace 键）
   - `Del` 按钮：删除全部输入（Delete 键）

### 科学计算
- **三角函数**：点击 `sin(`、`cos(`、`tan(` 按钮，输入角度值
- **数学函数**：`sqrt(16)` → 4.0，`ln(e)` → 1.0，`lg(100)` → 2.0
- **使用常量**：直接点击 `pi` 或 `e` 按钮插入常量

### 键盘快捷键

| 按键 | 功能 |
|------|------|
| `0-9` | 输入数字 |
| `+ - * /` | 运算符（* 和 / 会自动转换为 × 和 ÷） |
| `( )` | 括号 |
| `.` | 小数点 |
| `Enter` | 计算结果 |
| `Backspace` | 删除最后一个字符 |
| `Delete` | 清空输入 |
| `Escape` | 全部清空（AC） |

### BMR 健康计算
1. 点击 `BMR` 按钮打开健康计算器
2. 选择性别（男/女）
3. 输入年龄、身高（cm）、体重（kg）
4. 点击"计算 BMR"按钮
5. 查看基础代谢率结果和AI生成的健康报告

## 🐛 常见问题

### Q: 为什么音效无法播放？
A: 
1. 检查是否已安装 pygame：`pip install pygame`
2. 确认音频文件完整且未损坏
3. 检查是否开启了静音模式
4. 确认系统音量设置正常

### Q: 表情图片不显示怎么办？
A: 
1. 确认 `shucai/东海帝王王表情包/` 目录存在
2. 检查表情图片文件是否完整
3. 确认已安装 Pillow：`pip install Pillow`

### Q: 计算结果显示错误？
A: 
1. 检查表达式是否完整（括号是否匹配）
2. 确认没有除以零的情况
3. 验证输入的数值范围是否合理

### Q: AI功能无法使用？
A: 
1. 安装 dashscope：`pip install dashscope`
2. 检查网络连接
3. 确认API密钥有效
